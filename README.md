 Smart Port Identifier (Version 1)

A simple Python-based network utility that identifies common services running on well-known ports. 
This program accepts an IP address, subnet mask, and port number, then maps the port to its corresponding service.

Features
Accepts user input for:
IP address
Subnet mask
Port number
Identifies common network services based on port numbers
Displays a structured scan result
Beginner-friendly logic using conditional statements

 Explanation of Key Concepts

1. if vs elif:

if checks the first condition.
elif allows checking multiple conditions if previous ones fail.
Only the first true condition executes.

2. Input Validation:

A try-except block ensures the program doesn't crash if a non-numeric port is entered.

3. Default Values:

service and status are initialized to handle unknown ports safely.
